# 奶蛙Flash Tauri 真机验收矩阵

## 1. 使用边界

- 默认验收使用录制输出、临时目录、Wiremock HTTP 服务和注入进程执行器，不连接设备，不使用真实 Cloudflare token。
- 真机只允许在设备所有者明确批准、串号已核对、主机和 USB 连接可控时执行。任何“安全”分类都不等于可以在未经批准的设备上运行。
- 浏览器层可以只读接收封闭 `DeviceSnapshotDto` 中由 Rust 检测得到的 serial，用于展示当前设备；已注册设备命令不接受浏览器提交的 serial，实际 serial 始终来自 Rust 的当前设备快照。文件管理是明确例外：浏览器会把当前目录/条目中的受限设备路径，以及原生文件对话框返回的本地路径，提交给 `files_*` 命令；Rust 必须重新校验这些路径并生成固定程序与参数数组。浏览器不得获得会话 token、任意 shell、任意程序/参数或任意 HTTP 能力，所有执行仍由 `OperationCoordinator` 统一互斥、取消和收尾。
- 标记为“专用可恢复设备”的项目禁止在日用机、唯一设备、含未备份资料的设备或 bootloader 状态未知的设备上执行。
- 本矩阵是准入和记录模板，不代表本次任务已连接或改写任何真机。实际执行必须填写日期、操作者、批准人、设备资产编号/串号后四位、固件基线、产物哈希和恢复结果。
