# 品牌 Logo 与固定头像设计

## 目标

在已登录的主界面中复用登录页现有品牌 Logo，并为所有账号显示同一张内置头像；头像没有上传、编辑或切换入口。

## 范围

- 主应用框架的品牌区继续使用 `src/VivoKsu.App/Assets/logo.jpg`，与登录页使用同一份资源。
- 左侧栏账号区显示圆形固定头像，图片来源为用户指定的 `CEACC1A77693466C769A4EE631F407A2.jpg`，复制为前端受控静态资源后由 Vite 打包。
- 固定头像紧邻账号名称，不改变登录、登出、会话、权限或账号数据流。
- 不提供头像修改、选择、上传、远程下载或持久化配置功能。

## 组件与数据流

`Sidebar` 将导入静态头像 URL，并在账号信息块中渲染无交互的 `<img>`。账号名称仍由现有 `AppShell` / `App` props 传入；头像不依赖账号名称或服务端响应。Logo 沿用现有 `AppShell` 对 `logo.jpg` 的导入，不创建副本。

## 可访问性与视觉规则

- 固定头像提供说明性替代文本“默认头像”。
- 图片尺寸由 CSS 固定为圆形且使用 `object-fit: cover`，避免头像原始比例影响侧栏布局。
- 无按钮、文件输入框或可点击交互，因此键盘焦点和会话行为不变。

## 验收与测试

- 组件测试断言账号区存在固定头像、头像 URL 指向受控静态资源，且不存在头像编辑控件。
- 既有 AppShell 测试和前端构建通过。

## 非目标

- 不增加个性化头像、头像上传、用户资料页或远程头像服务。
- 不修改登录页 Logo、本轮资源内置实现或任何设备刷写逻辑。
